## 1. プロダクトの紹介

家計簿アプリを作りました。
家族で複数人で使えるようになっています。

## 2. こだわった点・苦労した点

一番最初のマイグレーションのファイルを複数項目を作れるようにするのに講義資料を見たりチャットGPTを使ったりし、解決しました。
こだわった点としては一覧からも詳細からも編集をできるようにしました。

## 3. 操作方法

1. トップページから「ログイン」または「新規登録」を行う
2. 「家計簿」から任意の 詳細を見る をクリックして詳細画面を開く
3. 編集　をクリックすることで編集画面を開く
4. 編集画面には　更新　と　削除　がありクリックすることで変更削除ができる
